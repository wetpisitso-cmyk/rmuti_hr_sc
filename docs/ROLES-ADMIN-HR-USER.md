# ระบบสิทธิ์ 3 ระดับ — ADMIN / HR / USER

## บทบาท

| role ใน hr_members | หน้าที่ | สิทธิ์เมนู |
|---|---|---|
| admin | ผู้ดูแลระบบสูงสุด และทำงาน HR ได้ | จัดการระบบและสิทธิ์, งานเจ้าหน้าที่ HR, บริการบุคลากร |
| hr | เจ้าหน้าที่บริหารงานบุคคล | งานเจ้าหน้าที่ HR, บริการบุคลากร |
| staff | USER บุคลากรทั่วไป | บริการบุคลากรเฉพาะสิทธิ์ |

- สมัครด้วยอีเมล @rmuti.ac.th + ยืนยันอีเมลได้รับ role='staff' เท่านั้น
- ADMIN เดิม: wetpisit.so@rmuti.ac.th ถูกเลื่อนจาก hr เป็น admin โดยเก็บข้อมูลและคำขอเดิม
- ADMIN เปลี่ยนบทบาทผู้ใช้ที่ยืนยันอีเมลแล้วได้จากเมนู **จัดการระบบและสิทธิ์**
- ห้ามเปลี่ยนบทบาทบัญชีของตนเอง; ป้องกันเหลือ ADMIN 0 บัญชี; มีประวัติผู้เปลี่ยน, เป้าหมาย และเวลาใน hr_role_audit
- ไม่เปิดการ INSERT/UPDATE/DELETE hr_members และ hr_role_audit โดยตรงให้ผู้ใช้หน้าเว็บ การแต่งตั้งต้องผ่าน RPC ตรวจ ADMIN จากฐานข้อมูล
- ADMIN สืบทอดสิทธิ์ HR (คำขอ/คำสั่ง/กิจกรรม/ครุภัณฑ์/รายงาน/การออก PDF); STAFF ไม่ได้สิทธิ์เหล่านี้
- HR ไม่สามารถเข้าหน้าจัดการสิทธิ์และเรียก RPC กำหนด role ได้
- RLS ป้องกันข้อมูลของคนอื่น; หน้าเว็บซ่อนเมนูเพื่อประสบการณ์ใช้งานที่เหมาะกับบทบาท

## ขั้นตอนกำหนดสิทธิ์

1. เข้าเว็บไซต์ https://wetpisitso-cmyk.github.io/rmuti_hr_sc/
2. ลงชื่อเข้าใช้บัญชี ADMIN
3. เมนูซ้าย: **จัดการระบบและสิทธิ์**
4. เลือกบัญชีผู้ใช้ (ต้องเป็น @rmuti.ac.th และยืนยันอีเมลแล้ว)
5. เลือก role USER / HR / ADMIN แล้วกด **บันทึกสิทธิ์**
6. ตรวจประวัติที่ส่วนล่างของหน้า
7. ผู้ใช้โหลดหน้าเว็บใหม่หรือเข้าสู่ระบบอีกครั้ง เพื่อให้เมนูอัปเดตตาม role ที่เปลี่ยน

## ความปลอดภัย

- ฟังก์ชัน public.hr_admin_set_role และ public.hr_admin_list_users ใช้สิทธิ์ elevated อย่างจำกัดโดยตรวจ hr_internal.is_admin() ที่ดู auth.uid(), verified email และ role จากฐานข้อมูล ไม่ดู user_metadata ที่แก้ได้
- การเปลี่ยน role ตรวจสอบผู้ใช้เป้าหมายและล็อกการแก้ไขก่อนบันทึกธุรกรรม
- ห้ามบุคลากรสมัครเองเป็น HR/ADMIN
- Google Drive Edge Function ตรวจ JWT + verified university email; role ADMIN/HR สามารถดำเนินการเอกสารตามสิทธิ์
- ระบบลงนามเอกสารตามลำดับแยกตัวผู้เสนอ/ผู้ตรวจสอบ/ผู้อนุมัติ/ผู้ลงนามไว้เช่นเดิม
- ยังต้องทดสอบการลงทะเบียน/อีเมลส่งจริงด้วย SMTP, Google Drive Service Account และเอกสาร PDF ก่อนใช้งานกับข้อมูลราชการจริง
